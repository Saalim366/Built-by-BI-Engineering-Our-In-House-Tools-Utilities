# Built by BI Engineering: In-House Tools & Utilities

A collection of tools and utilities developed in-house by the BI Engineering team to streamline report development, automate repetitive tasks, support database exploration, and improve validation and troubleshooting workflows.

## Available Tools

- **Display Options Utility**
- **Project Assignment Swap**
- **Project Assignment Migration**

## Usage & Contribution Guidelines

- **Read the documentation:** Review each tool’s purpose, requirements, and instructions before use.
- **Test before production:** Validate changes in a development or QA environment before using them in production.
- **Back up affected data:** Create a backup before running tools that modify data or report configurations.
- **Verify the target:** Confirm the correct company, database, reports, and projects before applying changes.
- **Protect sensitive information:** Never commit credentials, connection strings, or confidential customer data.
- **Document changes:** Update the relevant README with setup instructions, usage examples, and known limitations.
- **Follow code review:** Submit changes through a pull request for review before merging into the main branch.
- **Report issues clearly:** Include steps to reproduce, expected behavior, and relevant error details, with sensitive information removed.
